# Адаптивный интерфейс AetherMind

- **От 960 px:** широкий фон, приветствие в две колонки, четыре вкладки под шапкой, три карточки тарифов в строке; Dashboard показывает баланс и этапы рядом.
- **601–959 px:** мобильная навигация, две карточки тарифа в строке; профиль открывает отдельные разделы настроек.
- **До 600 px:** одна читаемая карточка тарифа в строке, зоны нажатия от 44 px; safe area Telegram и браузера учитывается едиными CSS-переменными.

Фон — векторный `cosmic-field.svg` без покадровой анимации (~9 КБ). Свет на широком экране меняется только по прозрачности одного декоративного слоя; режим снижения анимации и остановка при неактивном Telegram WebView сохраняются. Lottie загружается отдельным чанком только для экрана ожидания.

При проверке на реальном устройстве открыть приветствие и четыре раздела при ширине около 320, 390, 768 и 1280 px. Проверить отсутствие горизонтальной прокрутки, удобство нижней панели, раскрытие настроек, выбор языка и путь от тарифа к пополнению TON. Динамические GPU-показатели не добавлены без подключения телеметрии.
