# Адаптивный интерфейс AetherMind

- **От 960 px:** широкий фон во всё окно, приветствие в две колонки, навигация под шапкой, три карточки тарифов в строке, профиль с обзором и этапами рядом.
- **601–959 px:** обычная мобильная навигация, две карточки тарифа в строке, профиль одной колонкой.
- **До 600 px:** одна читаемая карточка тарифа в строке, крупные зоны нажатия, фон прокручивается вместе со страницей, настройки профиля свёрнуты, внизу учитывается safe area Telegram.

Фон — векторный `cosmic-field.svg` без покадровой анимации (~9 КБ). Свет на широком экране меняется только по прозрачности одного декоративного слоя; режим снижения анимации и остановка при неактивном Telegram WebView сохраняются. Lottie загружается отдельным чанком только для экрана ожидания.

При проверке на реальном устройстве открыть приветствие и четыре раздела при ширине около 320, 390, 768 и 1280 px. Проверить отсутствие горизонтальной прокрутки, удобство нижней панели, раскрытие настроек, выбор языка и путь от тарифа к тестовому заказу. Динамические GPU-показатели не добавлены без подключения телеметрии.
