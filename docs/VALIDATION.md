# Проверка поставки 0.1.0

## Выполнено перед передачей

- npm install с lockfile, prisma generate, TypeScript backend/frontend и production Vite build.
- 8 unit-тестов: HMAC initData, изменение данных, срок подписи, повторные ключи, другой токен бота, сессии, точный decimal-вывод BigInt, webhook secret.
- Миграция на embedded PostgreSQL (PGlite): создание таблиц, advisory lock, уникальность заявки, допустимые профили/статусы, запрет самореферала, уникальность источника ledger, точность сумм.
- bash -n обоих итоговых скриптов, ShellCheck шаблонов и серверного сценария. SC2016 исключён для намеренной передачи кода дочернему shell без подстановки в родителе.
- Python py_compile для settings.py и bot-config.py.
- Декодирование обоих установочных payload, совпадение SHA-256, наличие lockfile/миграции/ассетов/CI, отсутствие node_modules, сборок, cache и настоящих токенов.

## Ещё не выполнено

- Визуальное browser QA не завершено: штатный браузер не скачался, альтернативный не смог подготовить файлы в окружении проверки. Готовый Playwright-сценарий не считается пройденным.
- Полный HTTP integration.mjs с отдельным PostgreSQL предусмотрен в GitHub Actions, но запуск Actions произойдёт после публикации репозитория пользователем.
- Настоящий VPS, выдача/обновление сертификата и Telegram Bot API не проверялись из окружения разработки. Сценарий VPS проверяет их непосредственно при деплое.
- Нет подключённых GPU/API оплаты; безопасность приёма реальных денег и изоляция вычислительных задач не заявляются.

Нельзя трактовать успешную сборку как подтверждение коммерческой готовности всего сервиса.
