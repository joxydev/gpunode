## Оферта и акцепт

Текущая редакция: `88-2026-AI-NETWORK-2026-10-10-R2`.
Публичный документ: `/documents/public-offer-aethermind-network-2026-10-10-r2.pdf`.
SHA-256: `bfee177869e0c6d13c189df6eff3f772bb7a89509b9512711c3eb7ffdac52a0b`.

Пункт 8.1 и дополнение устанавливают действие с момента публикации на платформе.
VPS записывает фактическое UTC время выпуска: `effectiveAt = publishedAt`.
Повторный запуск сохраняет дату публикации той же редакции. При обновлении реестра
сохраняется прежняя запись, а `NETWORK_PROGRAM_STARTED_AT` оставляет исходную границу
событий программы. Ожидавшие обработки события прежнего выпуска не теряются.

В публичном каталоге один актуальный PDF. Предыдущий сетевой документ сохранён
побайтно в закрытом архиве; старый публичный URL возвращает HTTP 410. Документ
ранее заключённого договора доступен только его владельцу через защищённый API.
Существующие акцепты и неизменяемые условия договоров не переписываются.
Удалён неиспользуемый устаревший перевод оферты и повторные пункты меню.

После загрузки аккаунта без акцепта R2 сразу открывается актуальная оферта — также
для пользователей с прежним акцептом. Окно можно закрыть, остаётся напоминание.
Открытие PDF и явная отметка согласия разрешают кнопку принятия. Автоматического
акцепта нет. Существующий свободный баланс и договоры доступны без нового акцепта;
новый заказ требует актуальную редакцию, как и ранее.

## Изображения

Все собственные растровые изображения выводятся через CSS фон вместо HTML img:
язык, запуск, логотипы, согласие, тарифы, GPU и партнёрский баннер. Изображения
не обёрнуты ссылками. Capture обработчики contextmenu/dragstart работают также
в начальных экранах и порталах. Прокрутка, кнопки и текстовые/PDF ссылки сохранены.
Для сторонних img отключены pointer events, вызов меню и перетаскивание.
