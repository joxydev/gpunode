# AetherMind · GPU Node

Мобильный Telegram Mini App для участия в коммерческом DePIN-кластере GPU. Интерфейс и серверная модель приведены в соответствие с публичной офертой № 88/2026-AI от 14.09.2026, подписанной 21.09.2026.

> Текущий релиз не принимает деньги и не начисляет доход. Он фиксирует документы, сохраняет выбранную категорию и показывает этапы пользователя. Платёжные, расчётные и GPU-модули подключаются отдельными проверяемыми релизами.

## Реализовано

- Первый вход: пользовательское соглашение, затем обязательный акцепт актуальной публичной оферты с прокруткой до конца, подтверждением и фиксацией версии, SHA-256 документа, времени и защищённого отпечатка клиента.
- «Профиль» вместо дашборда: учётный баланс USDT, выбранный тариф и пять этапов — регистрация, выбор тарифа, пополнение, заказ тарифа, вывод после Epoch.
- Компактный мобильный каталог фиксированных категорий оферты:
  - Node Alpha — 50 USDT, 30 дней, базовый расчёт 1,5% в сутки;
  - Cluster Beta — 300 USDT, 60 дней, 2,5% в сутки;
  - Enterprise POD — 1 200 USDT, 90 дней, 3,5% в сутки;
  - Quantum Array — 5 000 USDT, 180 дней, параметры в разработке, категория недоступна.
- Выбор доступной категории сохраняется в профиле без списания средств. Конкретное оборудование и B2B-нагрузку назначает Оператор.
- Партнёрская ссылка `/start r_ID`, запрет самореферала и анонимизированное отображение фактических этапов приглашённых. Оферта не устанавливает денежную реферальную выплату, поэтому интерфейс её не обещает и не начисляет.
- Отдельная вкладка владельца: сводные показатели, поиск пользователей, профиль с балансом, подтверждённым депозитом, датой регистрации и полным списком приглашённых.
- Заявки на подключение оборудования: пользователь, категория оборудования, этап обработки и независимый статус платежа `Ожидает оплаты / Оплачено`. Пока платёжный модуль выключен, новые заявки получают только статус ожидания.
- Поддержка в формате полноценного тикет-чата: история сообщений, непрочитанные ответы, продолжение диалога до закрытия оператором и отдельный компактный журнал действий.
- Telegram initData HMAC-проверка, короткоживущая серверная сессия, PostgreSQL, аудит, CSP и ограничение API-запросов.
- Точная PDF-копия оферты доступна в приложении; её SHA-256 проверяется в CI и при деплое.

## Пока выключено

- Пополнение, внутренние списания, вывод, QR, платёжные webhooks и любые операции с реальными средствами.
- Автоматические начисления, Compound Boost, запуск Epoch, создание `user_leases` через публичный API и реальное назначение GPU.
- Выплаты за приглашения: соответствующего условия нет в предоставленной оферте.
- Quantum Array: это будущая категория с неопубликованными ставками, а не доступный тариф.

API `/api/payments`, `/api/withdrawals` и `/api/v1/market/buy` закрыты и не изменяют баланс. Расчётные значения в карточках показывают арифметику условий оферты, а не факт начисления.

## Стек

React 18, TypeScript, Vite 7; NestJS 11 + Fastify; Prisma 7 + PostgreSQL; Node.js 22; Nginx + systemd. Шрифты и ключевые ассеты обслуживаются локально. Интерфейс рассчитан на Telegram WebView и экраны от 320 px.

## Обновление этого релиза

В Termux последовательно запустите два подготовленных скрипта:

```bash
chmod 700 ~/storage/downloads/30_aethermind_owner_center_github.sh \
          ~/storage/downloads/31_aethermind_owner_center_vps.sh
bash ~/storage/downloads/30_aethermind_owner_center_github.sh
bash ~/storage/downloads/31_aethermind_owner_center_vps.sh
```

Первый скрипт проверяет исходный коммит, накладывает воспроизводимый patch, создаёт резервную ветку, коммитит и отправляет `main` в `joxydev/gpunode`. Второй архивирует ровно опубликованный SHA, передаёт его по SSH и запускает атомарную сборку и проверки на VPS. Токен бота и `runtime.env` повторно не запрашиваются и не выводятся.

При сбое до активации рабочая версия продолжает обслуживать пользователей. При ошибке после переключения systemd-сервиса восстанавливается предыдущий релиз. Миграция только добавляет поля и таблицу; перед ней создаётся дамп PostgreSQL.

Доступ: <https://31.77.226.26/>. После успешного обновления полностью закройте и заново откройте Mini App, чтобы Telegram WebView загрузил новый bundle.

## Разработка и проверки

```bash
npm ci --ignore-scripts --no-audit --no-fund
npm run db:generate
npm test
npm run build
```

Полный HTTP-набор требует PostgreSQL. VPS-деплой создаёт отдельный временный кластер PostgreSQL на случайных локальных портах, применяет все миграции и проверяет авторизацию, оба документа, выбор тарифа, этапы профиля, партнёрский учёт, список и карточку пользователей владельца, статусы заявок, тикет-чаты, уведомления и закрытые финансовые маршруты до переключения релиза.

Эксплуатация:

```bash
sudo systemctl status gpunode --no-pager
sudo journalctl -u gpunode -n 80 --no-pager
sudo systemctl list-timers gpu-cert-renew.timer --no-pager
curl --fail https://31.77.226.26/api/health
```

Не публикуйте `/srv/apps/gpunode/shared/runtime.env`. Релизы находятся в `/srv/releases/gpunode`, резервные копии — в `/srv/backups/gpunode`.
