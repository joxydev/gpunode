# AetherMind · GPU Node

Мобильный Telegram Mini App для участия в коммерческом DePIN-кластере GPU. Интерфейс и серверная модель приведены в соответствие с публичной офертой № 88/2026-AI от 14.09.2026, подписанной 21.09.2026.

> Обычное пополнение USDT в TON Mainnet автоматически зачисляется после проверки watcher. Gasless для совместимых W5-кошельков открывается отдельным canary и отдельным подтверждённым платежом. Заказ оборудования и начисления пока выключены. Запросы на вывод обрабатываются вручную через поддержку.

## Реализовано

- При первом открытии выбор русского, английского или румынского языка; смена языка в профиле с сохранением в аккаунте. Интерфейс, ответы API, команды бота и ознакомительные переводы документов доступны на выбранном языке. Оригинальные PDF и версии акцепта не меняются.
- Первый вход: пользовательское соглашение, затем обязательный акцепт актуальной публичной оферты с прокруткой до конца, подтверждением и фиксацией версии, SHA-256 документа, времени и защищённого отпечатка клиента.
- Навигация «Главная / Тарифы / Финансы / Профиль» (для владельца также «Управление»). Главная показывает учётный баланс, состояние из `/me.nextAction`, путь участия, реальные Epoch и последние действия. Профиль содержит настройки, кошельки, ноды, документы и партнёров.
- Компактный мобильный каталог фиксированных категорий оферты:
  - Node Alpha — 50 USDT, 30 дней, базовый расчёт 1,5% в сутки;
  - Cluster Beta — 300 USDT, 60 дней, 2,5% в сутки;
  - Enterprise POD — 1 200 USDT, 90 дней, 3,5% в сутки;
  - Quantum Array — 5 000 USDT, 180 дней, параметры в разработке, категория недоступна.
- Выбор доступной категории сохраняется в профиле без списания средств. Конкретное оборудование и B2B-нагрузку назначает Оператор.
- Партнёрская ссылка `/start r_ID`, запрет самореферала и анонимизированное отображение фактических этапов приглашённых. Оферта не устанавливает денежную реферальную выплату, поэтому интерфейс её не обещает и не начисляет.
- Отдельная вкладка владельца: сводные показатели, поиск пользователей, профиль с балансом, подтверждённым депозитом, датой регистрации и полным списком приглашённых.
- Заявки на подключение оборудования: пользователь, категория оборудования, этап обработки и независимый статус платежа `Ожидает оплаты / Оплачено`. Автоматическая оплата тарифа пока не подключена; новые реальные заявки ожидают решения Оператора.
- Поддержка в формате полноценного тикет-чата: история сообщений, непрочитанные ответы, продолжение диалога до закрытия оператором и отдельный компактный журнал действий.
- Telegram initData HMAC-проверка, короткоживущая серверная сессия, PostgreSQL, аудит, CSP и ограничение API-запросов.
- Точная PDF-копия оферты доступна в приложении; её SHA-256 проверяется в CI и при деплое.
- Подключение TON-кошелька через TON Connect и проверка владения через TON Proof; счета USDT TON формирует backend. Отдельный watcher сверяет уведомление от официального USDT Jetton Wallet treasury, invoice и сумму, затем атомарно записывает подтверждённый депозит в реальный баланс и `wallet_ledger`. Депозиты с ошибками требуют ручной проверки. Подробности: `docs/TON_USDT.md`.
- Gasless-контур для W5 с объявленным `SignMessage` минимум на две операции: TONAPI оценивает отдельную комиссию в USDT, backend сверяет оба действия и подпись, watcher подтверждает зачисление. До реального canary режим для всех закрыт; обычный перевод остаётся доступен для остальных кошельков.

## Пока выключено

- Внутренние списания реального баланса, автоматический вывод и другие сети.
- Автоматические начисления, Compound Boost, запуск Epoch, создание `user_leases` через публичный API и реальное назначение GPU.
- Выплаты за приглашения: соответствующего условия нет в предоставленной оферте.
- Quantum Array: это будущая категория с неопубликованными ставками, а не доступный тариф.

Старые API `/api/payments`, `/api/withdrawals` и `/api/v1/market/buy` закрыты. Новое пополнение доступно только через `/api/v1/deposits` с подтверждённым TON-кошельком и независимой проверкой блокчейна. Расчётные значения в карточках не являются фактом начисления.

## Стек

React 18, TypeScript, Vite 7; NestJS 11 + Fastify; Prisma 7 + PostgreSQL; Node.js 22; Nginx + systemd. Шрифты и ключевые ассеты обслуживаются локально. Интерфейс рассчитан на Telegram WebView и экраны от 320 px.

## Обновление gasless этапа

Развёртывание берёт точный коммит GitHub и собирает его на VPS. Режим и параметры обычных депозитов сохраняются; gasless остаётся выключенным, пока оператор отдельно не откроет `gasless-canary` при действующем стандартном `canary` или `public`. Этот режим запросит TONAPI API key скрытым вводом, если он ещё не сохранён. После нового реального W5 платежа с `SignMessage` и автоматическим `CREDITED` команда `gasless-all` проверяет on-chain перевод всей суммы invoice, отдельную USDT-комиссию в том же trace и единственную запись ledger. Только после этой проверки, если обычные депозиты были в `canary`, открываются одновременно обычные депозиты и gasless для всех совместимых кошельков. Бот и Telegram token не меняются; ключи не добавляются в Git.

Перед миграцией создаётся дамп БД и копия конфигурации. При сбое переключения восстанавливаются предыдущий релиз, Nginx, unit и secrets. Добавочная миграция БД автоматически не откатывается.

Доступ: <https://31.77.226.26/>. После успешного обновления полностью закройте и заново откройте Mini App, чтобы Telegram WebView загрузил новый bundle.

TON Connect manifest включает `privacyPolicyUrl` на `/privacy`. Для будущего публичного HTTPS-домена укажите `AETHERMIND_PUBLIC_ORIGIN=https://example.org` при сборке frontend: post-build скрипт перенесёт существующие `url`, `iconUrl`, `termsOfUseUrl` и `privacyPolicyUrl` на этот origin, сохранив пути. Без переменной остаётся текущий HTTPS IP. Текст Privacy помечен `LEGAL_REVIEW_REQUIRED` до юридической проверки реквизитов и сроков хранения.

## Разработка и проверки

```bash
npm ci --ignore-scripts --no-audit --no-fund
npm run db:generate
npm test
npm run build
```

Полный HTTP-набор требует PostgreSQL. VPS-деплой запускает отдельный временный кластер PostgreSQL, применяет миграции и проверяет прежние сценарии, защиту TON API, блокировку публичных счетов, ручную сверку, повторы blockchain транзакции и единственное зачисление.

Эксплуатация:

```bash
sudo systemctl status gpunode --no-pager
sudo journalctl -u gpunode -n 80 --no-pager
sudo systemctl list-timers gpu-cert-renew.timer --no-pager
curl --fail https://31.77.226.26/api/health
```

Не публикуйте `/srv/apps/gpunode/shared/runtime.env`. Релизы находятся в `/srv/releases/gpunode`, резервные копии — в `/srv/backups/gpunode`.
